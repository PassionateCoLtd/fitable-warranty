# FITABLE 보증 등록

> 작성자: Codex · 2026-10-22

외부몰을 포함한 구매자와 브랜드를 직접 연결하고, 구매정보를 한 번 확인하여 이후 A/S 확인 부담을 줄이기 위한 보증 등록 서비스의 첫 시안입니다.

## 현재 산출물

- `index.html`: 모바일 대응 등록 체험. 구매처별 안내, 증빙 예시, 입력 검증, 확인 화면, 접수 대기 안내.
- `plan.html`: 목적, 범위, 현재 진행, 실제 접수 전 완료 조건, 측정 지표.
- `card.html`: 제품별 공통 QR 안내물 시안.
- `qr-opb01.svg`: 체험 화면에 연결되는 QR. 정식 동봉용이 아닙니다.

## 실행

```sh
python3 -m http.server 5086 --bind 127.0.0.1
```

GitHub Pages에서 별도 빌드 없이 제공할 수 있습니다. 자사몰 스킨과 기존 앱은 수정하지 않습니다.

## 시안과 실제 운영의 경계

이 버전은 **실제 접수 서비스가 아닙니다**. 입력은 페이지 메모리에만 있으며 저장소·API·분석 서비스·문자로 전송하지 않습니다. 실제 파일을 선택하는 기능 대신 예시 증빙 버튼을 사용합니다. CSP의 `connect-src 'none'`과 `form-action 'none'`으로 데이터 전송을 막습니다. 완료 화면은 실제 접수가 없었음을 명시합니다.

보증기간, 연장, 적립금, 개인정보 보유기간은 확정하지 않았습니다. 주문번호 존재만으로 구매자 인증이나 보증 승인을 하지 않습니다. 등록이 회원가입 또는 마케팅 동의를 대신하지 않습니다.

## 실제 접수 연결의 다음 범위

1. 제품별 보증 정책과 개인정보 처리 기준 확정.
2. 별도 HTTPS 접수 서버와 비공개 데이터 저장소, 관리자 접근 제어 구현.
3. 구매자 확인·제품/날짜/취소/반품 대조, 중복·다중 수량·재접수 처리.
4. 이미지 유형·크기 검사, 업로드 접근 제어, 기록 삭제·보존 처리.
5. 접수/확인대기/보완요청/승인/반려 상태와 결과 조회. 문자 발송은 별도 연결·승인.
6. 테스트 주문으로 전체 흐름 검수 후 실제 접수 활성화, 고정 QR 주소 확정 후 인쇄.

고객정보, 주문 데이터, 증빙, 인증키는 이 공개 저장소에 넣지 않습니다.

## 공식몰 회원 연동 (2026-10-22 추가)

첫 화면에 실제 공식몰 로그인(`/member/login.html`)과 회원가입(`/member/join.html`) 링크를 연결했습니다. 둘 다 직접 화면을 열어 확인했습니다. `가입 없이 시안 체험하기`는 회원가입·로그인으로 처리되지 않습니다.

카페24 공식 회원 인증 프로세스는 외부 서비스에서 로그인 → 회원 정보 제공 동의 → 인증 코드/토큰 교환 → 회원 고유 식별자 조회를 지원합니다. 이를 통해 보증 기록을 자사몰 회원에 연결할 수 있습니다. 현재 버전은 이 자동 인증을 연결하지 않았습니다.

- 실제 연결 전 카페24 앱의 회원 인증 권한과 HTTPS 복귀 주소 설정이 필요합니다.
- 인증 코드는 별도 서버에서 검증·교환하고, 회원 고유 식별자와 보증 기록을 연결합니다. 공개 페이지에 비밀키를 넣지 않습니다.
- 로그인 버튼 클릭, 공식몰 창 닫기, 가입했다고 스스로 표시하기는 인증으로 취급하지 않습니다.
- 회원 식별자 인증과 이름/휴대폰 조회는 별개입니다. 식별자만으로 연락처 자동 채움을 약속하지 않습니다.
- 자사몰 회원 확인과 쿠팡/네이버 주문의 구매 증명도 별개입니다.
- 정식 서비스는 인증 서버와의 도메인·세션·모바일 복귀를 검수한 뒤 공개합니다.

공식 근거: https://developers.cafe24.com/app/front/app/develop/customeraccesstoken/process

## 와이드 풀업바 운동 프로그램

[체험 열기](https://passionatecoltd.github.io/fitable-warranty/program/). 회원 입구 → 내 기구 등록 → 목표·운동·보조 조건 → 실제 세트·휴식 → 결과·내 기록 순서로 구성했습니다. 매달리기, 견갑골 당기기, 풀업, 밴드 보조 풀업을 구분합니다.

- 0회 시도와 건너뛰기, 수정·완료 취소·중간 종료.
- 새로고침 뒤 진행 위치·타이머·입력 복원.
- 같은 운동·그립·보조 조건의 처음·최근·최고 기록.
- 최근7일 완료 세트 분포와30일 기록 달력.
- 명시적 체험, 브라우저 저장·내보내기·초기화. 실제 개인정보를 입력하지 않습니다.

공개 파일은 별도 비공개 구현 저장소의 `web/`에서 가져옵니다. 서버 코드는 이 저장소에 배포하지 않습니다. 카페24 회원 인증 앱 설정과 운영 HTTPS 서버 연결이 남아 있어 실제 회원 연동은 비활성화되어 있습니다. 운동별 상세 처방·자동 진급·자체 영상은 준비 전이며 사용자가 직접 세트·목표·휴식을 정합니다.

## 2026-10-22 사용 검수 반영

타이머 세트 귀속, 새로고침 이어하기, 수정 취소, 저장 실패 시 기존 상태 유지, 밴드 보조 조건, 세트 저장 순서에 따른 통계를 고쳤습니다. 자동 테스트는 비공개 원본에서 Python67개·JS17개를 통과했습니다. 발견·수정·재검수의 자세한 기록과 내부 근거는 비공개 구현 저장소에서 관리합니다.


## 초보자 UX 개선 — 2026-10-22

- 운동을 고를 때 이름과 동작 그림을 함께 보여줍니다. 어깨 내리기(견갑골 당기기), 턱걸이(풀업)처럼 쉬운 이름을 먼저 씁니다.
- 준비/동작 그림과 짧은 설명을 운동 중에도 볼 수 있습니다. 직접 만든 SVG 설명 그림이며 실제 촬영 영상은 아닙니다.
- 처음에는 매달리기10초×2세트/1분 휴식, 어깨 내리기5회×2/1분, 이미 가능한 턱걸이1회×2/2분의 시작 예시를 보여줍니다. 펼쳐서 자유롭게 바꿀 수 있습니다.
- 위 조합은 FITABLE의 시작 예시입니다. 개인 처방으로 표시하지 않으며, 공식 자료의 참고 범위와 주의사항을 화면에서 확인할 수 있습니다. 밴드는 제품 호환 확인 전 자동 추천하지 않습니다.
- 참고 목표를 실제 수행 기록으로 자동 저장하지 않습니다. 기록칸에는 실제 한 만큼만 적습니다.
- 화면 파일6개만 배포합니다. 실제 회원 인증·보증 접수 서버 설정 상태는 이전과 같습니다.


## 운동 이미지 스타일 비교 시안

[시안3종 보기](https://passionatecoltd.github.io/fitable-warranty/program/style-preview/). `program/style-preview/`에 A실사 느낌/B3D인체/C스포츠 일러스트를 같은 운동 화면으로 비교합니다. 기존 운동 프로그램 기능·기록과 별도의 시안입니다.

이미지는 built-in image_gen으로 생성한 정지 이미지이며 실제 제품 촬영물·영상·검증된 교습 자료가 아닙니다. 이미지 원본은 해당 경로의 `assets/`에 있습니다. 타 앱 그림은 복사하지 않았으며 공식 참고 링크만 제공합니다. 모바일 스타일 전환과 확대 기능을 제공합니다.

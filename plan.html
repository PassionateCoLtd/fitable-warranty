회원가입 연동 / 공식 지원 확인

공식몰 계정을 보증 등록에도 사용합니다

가능한 연결: 카페24는 외부 서비스에서 공식몰 회원을 인증하고 고유 식별자로 연결하는 기능을 제공합니다. 기존 회원은 같은 계정을 사용하고, 신규 고객은 공식몰에서 가입한 후 인증합니다.

권장 흐름: QR 접속 → 공식몰 로그인 또는 회원가입 → 회원 정보 제공 동의·인증 → 보증 구매정보 입력 → 해당 회원에 등록 내역 연결.

현재 구현: 공식몰 로그인·회원가입 화면으로 이동하는 버튼과 회원 연결부터 시작하는 시안. 링크를 열었다는 이유로 로그인 완료나 회원 연결 완료로 처리하지 않습니다.

자동 연동에 필요한 것: 카페24 회원 인증 앱 설정, 회원 식별자 권한·인증 후 돌아올 주소 등록, 별도 서버에서의 회원 인증 및 보증 기록 연결. 공식몰 로그인 쿠키를 GitHub 페이지가 직접 읽는 방식은 사용하지 않습니다.

구분: 회원 인증은 누구의 계정인지 확인하는 단계이며, 외부몰 제품의 구매 여부는 주문정보·증빙으로 별도 확인합니다. 회원 식별자 인증만으로 이름·휴대폰이 자동 채워지지는 않습니다.

공식 근거: 카페24 쇼핑몰 회원 인증 프로세스 ↗

가장 단순한 시작

01 / 같은 QR제품별 공통 QR을 설명서 또는 안내물에 인쇄
02 / 구매정보회원 인증 후 제품·구매처·주문번호·구매일 입력
03 / 확인 대기주문정보와 구매 증빙을 대조
04 / 결과 안내확인된 제품 정책에 따라 등록 결과 안내

첫 버전의 범위

  • 시작 제품: 와이드 풀업바. 다른 제품은 보증 정책 확인 후 순차 추가합니다.
  • QR: 제품마다 한 개. 박스별 시리얼은 만들지 않습니다. 배치 추적이 필요하면 QR의 배치 표지만 추가하고, 이를 구매 증빙으로 사용하지 않습니다.
  • 구매 확인: 초기에는 확인 대기로 접수합니다. 주문번호가 존재하는지만으로 승인하지 않고 제품·구매일·취소/반품 여부·구매자 확인 방법을 함께 검토합니다.
  • 자동화: 자사몰·네이버의 실제 데이터와 본인 확인 수단 검증 후 적용합니다. 검증되지 않은 주문은 수동 확인으로 넘깁니다.
  • 쿠팡·기타: 판매처·제품명·주문번호·구매일이 보이는 증빙으로 확인합니다. 불필요한 주소·결제정보는 가리도록 안내합니다.
  • 회원·마케팅: 공식몰 계정 인증을 보증 등록의 입구로 설계합니다. 마케팅 수신 동의는 별도로 받으며, 일반 A/S 권리가 회원가입·등록 유무로 제한된다고 안내하지 않습니다.

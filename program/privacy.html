운동 일지 보관

로그인 없이 한 운동 일지는 현재 브라우저에 저장돼요 — 다른 기기나 브라우저에서는 이어볼 수 없어요

회원으로 시작한 운동은 회원 고유 식별자와 연결해 서버에 저장해요 — 로그인 없이 한 일지와 회원 일지는 자동 합쳐지지 않아요

회원 연결과 파일럿 참여

카페24 로그인에서 인증된 회원 아이디와 고유 식별자를 사용해 같은 회원의 운동 일지를 연결해요 — 회원 연결 시각과 횟수도 보관해요 — 비밀번호와 카페24 액세스 토큰은 저장하지 않아요

운영자는 회원 아이디별 운동 일수·종류·저장한 세트·시간·횟수를 확인해 파일럿 운영에 사용해요 — 구매 확인이나 보증 승인을 대신하지 않아요

참여 분석 — 선택 동의

동의한 뒤 방문 시각·화면·누른 버튼·운동 선택·저장·완료 이벤트·재방문을 회원 아이디와 연결해 프로그램을 개선해요 — 다른 기기도 같은 회원으로 합쳐요

기본 상태는 동의하지 않음이에요 — 동의하지 않아도 회원 운동 일지는 이용할 수 있어요

분석에 이름·연락처 입력 내용, 비밀번호, 자유 입력 메모, 통증·불편함 응답, 전체 방문 주소를 보내지 않아요 — 광고 플랫폼에도 보내지 않아요

보관·철회·삭제

회원 아이디 연결과 일지를 지우려면 내 계정 → 이 서비스의 내 정보 삭제를 이용해 주세요 — 이용이 어려우면 고객센터에 문의해 주세요 — 회원의 운동 정보는 내 계정에서 내려받거나 삭제할 수 있어요
